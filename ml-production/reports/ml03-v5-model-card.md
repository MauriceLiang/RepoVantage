# ML-03 v5 时间形态研究模型卡

状态 `research_only`；未批准生产加载。该模型将仓库按 Commit 和新建 PR 在 52 周中的时间分布聚类，用于研究活动形态差异，不预测未来事件，不输出采用建议、质量得分或聚类概率。

训练输入为 2025-11-03 00:00 UTC 至 2026-11-02 00:00 UTC 的 52 个完整周。仅纳入 Commit 与全部状态新建 PR 均完整覆盖、且分别至少有 20 次和 10 次事件的仓库；训练 140 个，历史验证 48 个。默认分支以采集时 SHA 可见历史为准，不能还原过去时点的分支成员或被删除的 PR。

模型为 `StandardScaler` 与 `KMeans(K=2)` 组成的训练流水线，随机种子 20261109。输入是 Commit 和新建 PR 周事件份额的归一化 Shannon 熵；缩放器和聚类中心只在历史训练仓库拟合。历史训练中 50 次以仓库为单位的重采样 OOB ARI 第 5 百分位为 0.9171，活动量三分位 NMI 为 0.2158；历史验证轮廓系数为 0.6417。各簇的训练事实、中心和边界样例见 `dataprepare/MachineLearn/run/ml03-v5-development/cluster_profiles.json`，其中的编号没有经过真人语义审核。

不完整、历史不足、活动量低于范围、特征越过训练范围或距簇中心超过训练簇内距离 99 分位的输入不应强制归类。历史训练与验证不能证明对外部语言、项目类型或未来数据的泛化；熵可能与活动规模相关，已纳入规模混杂和分层对照，但业务意义仍需真实双人复核。

首个不同候选在单独 60 仓库外部测试上未达门槛，失败结果已冻结；本候选及另一批互不重叠的 75 仓库在正式评分前冻结。第二批中 45 个仓库完整且在分布内，形态轮廓系数相对规模基线增益 +0.2671，但拒判率 40% 高于冻结的 35% 上限，独立数值验收未通过。真实双人复核、分歧仲裁和负责人批准均尚缺失，详见 `external-validation-v5.md`。

模型、训练清单、特征、预处理、簇画像和哈希索引位于 `dataprepare/MachineLearn/run/ml03-v5-development/`；哈希同时保存在 `ml-production/manifests/ml03_v5_artifact_index.json`。研究 `joblib` 只能在可信且哈希匹配的研究环境加载；产品运行时只接受受控数值 JSON 及匹配的完整批准记录。记录中人员身份需人工和部署权限核实。
