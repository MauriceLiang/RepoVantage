# 模型生命周期与研究证据

本目录存放模型注册、版本化验证清单、冻结实验协议和机器可读评估证据。与 `ml/course/` 的课程训练、固定切分和模型产物分开维护。

- `registry.json`：模型版本及当前注册状态。
- `manifests/`：特征、来源哈希、数据切分及外部留出集等锁定清单。
- `protocols/`：模型评估、验收和发布协议版本。
- `reports/`：可复查的机器可读验证结果。
- `scheduling/`：影子运行安排及可复查执行记录；运行日志和锁文件不得提交。
- `approved/`：已批准模型的受信任存放位置，目前无批准模型，详见 [approved/README.md](approved/README.md)。

**重要边界：** 已训练、注册或获得历史测试分数并不代表生产上线批准。外部验证、人工复核和负责人审批应遵循冻结协议；仓库不应把研究评估写成生产质量保证。
