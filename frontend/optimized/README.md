# RepoVantage 优化版前端

这是与正式前端隔离的交互原型，所有仓库、指标和任务均为本地 Mock 数据，不调用 API，也不会触发采集任务。保留现有的 Vue、ECharts 与 Lucide 图标体系，并使用天蓝到深蓝的主色层级。

## 启动

在 macOS / Linux 的仓库根目录运行：

```bash
npm --prefix frontend/optimized run dev
```

预览地址：`http://127.0.0.1:5180/`。运行时复用 `frontend/node_modules` 中已安装的依赖。

构建：

```bash
npm --prefix frontend/optimized run build
```

## 页面

- 总览：300 个模拟仓库的关注度、技术栈、活动和六种数据分布图表。
- 仓库：搜索、语言筛选、选择并比较、直接打开仓库分析。
- 项目比较：候选管理、无级权重调整、手动权重和 0–100 综合分。
- 研究分析：固定 300 仓库样本、分组对照、覆盖情况和样本列表。
- 仓库分析：概览、活动、Issue、PR、Release 五个内容页签。
- 任务中心：模拟任务状态；浅色/深色主题通过顶部导航切换。

## 共享组件

在 `components.html` 可以预览共享按钮、状态标签、输入框、选择框、指标卡片、导航项、页面标题和内容面板的常见状态。操作按钮统一为 36px 高；应用页面和组件样例共用同一套组件注册入口。

演示数据仅用于检查信息层级、图表与交互，不代表当前数据库或 GitHub 实际数据。
