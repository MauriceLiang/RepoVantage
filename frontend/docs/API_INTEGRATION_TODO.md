# 后端接入状态与数据边界

Vue 前端默认通过 `HttpRepositoryDataSource` 访问 `/api/browser/v1`。浏览器先建立本机会话，再使用 CSRF 校验提交变更请求；内部 API Key 仅由服务端网关持有。`VITE_DATA_MODE=mock` 仅供显式原型演示，HTTP 失败时不会回退到 Mock。

## 已接入

| 页面/操作 | 后端能力 | 前端表现 |
|---|---|---|
| 总览与仓库列表 | 仓库列表、搜索、解析、加入、移除 | 显示真实仓库状态；新增仓库进入真实采集任务 |
| 仓库分析 | 分析结果、事件 Insights、覆盖质量、深度刷新 | 展示周趋势、耗时分布和近一年正式 Release；仅呈现 API 返回的数据 |
| 项目比较 | 共同完整自然周及仓库指标 | 只绘制仓库共有的完整周，缺失指标为 `—` |
| 研究分析 | 研究数据集、统计结果、质量报告 | 展示真实样本、分组、相关性和缺失率 |
| 任务中心 | 任务列表与任务重试 | 轮询服务端状态，显示已知阶段和后端错误 |
| CSV | 仓库 Insights、项目比较、研究成员导出 | 使用后端生成的 CSV 内容下载 |

## 后端尚未提供

- Commit 日级序列、作者排行和逐条 Commit 明细。
- Issue/PR 的逐条标题、编号、时间戳、open 列表和评论信息；Release tag 名称（当前仅有 Release ID 与日期）。
- 可按 30 天重新计算的仓库指标；当前仓库 Insights 使用 90 天活动窗口，发布节奏使用近 365 天窗口。
- 比较结果的任意日期窗口；当前只按后端共同完整自然周比较。

这些字段在界面中保持空缺或说明限制，不从 Mock、总数或样本估算。新增上述分析体验前，需要先扩充后端接口与数据契约。
