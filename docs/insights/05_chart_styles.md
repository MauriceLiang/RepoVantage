# RepoVantage 图表说明

唯一正式前端位于 `frontend/src/`，使用 Vue 3、TypeScript、Vite 与 AntV G2 5。页面使用真实 `RepositoryDataSource` 数据；图表保留后端原始值、单位、时间范围和覆盖语义。Mock 数据仅在显式演示模式运行。

## 业务图表映射

| 页面/问题 | 正式图表 | 数据边界 |
|---|---|---|
| 总览：仓库语言与活动样本 | G2 treemap、区间柱、Stars/Forks 点图、年份频数、语言周均值、活跃周频数 | 使用仓库资料/已采集分析，缺少值不会按零填充；散点标明对数坐标与排除规则 |
| 研究：300 个仓库样本的周活动 | G2 研究轨迹和散点图 | 按真实样本和 12 周记录筛选；保留研究样本和训练/测试用途 |
| 选型：候选的多维证据 | G2 平行坐标、候选散点、周活动线 | 不对缺失指标插补；未覆盖的样本保留原始证据说明 |
| 比较：候选时间序列和耗时 | G2 候选趋势与耗时对比 | 只使用比较接口返回的时间窗口、样本量和质量字段 |
| 详情概览：提交、账号和 Release | 分开的 G2 时间趋势与事件泳道 | Commit/账号/Release 使用自己的单位；UTC 周和真实 Release 日期 |
| 详情活动：作者贡献和连续性 | G2 作者堆叠、四周均值、洛伦兹曲线；Vue/CSS 日历热力 | Commit 周和作者统计来自仓库分析接口；日历只显示所给数据和覆盖状态 |
| 详情 Issue：吞吐与关闭耗时 | G2 周新增/关闭柱、差值线、耗时桶 | 差值只在完整周计算；耗时只按 API 返回的桶展示 |
| 详情 PR：吞吐与合并耗时 | G2 周合并数量、逐条耗时点、周中位数、周期桶与中位数 | 使用实际 PR 样本、月/周聚合和 `n`；P90 长尾保持真实值 Tooltip |
| 详情 Release：发布时间和节奏 | G2 日期泳道与间隔区间柱 | 只按实际 Release 时间戳和本地已采集间隔绘制；Commit 覆盖说明单独显示 |

## 图表基础设施

- `frontend/src/components/charts/G2Chart.vue` 创建单实例 G2 Chart，使用 `autoFit`，响应数据和主题变化，并在卸载时调用 `destroy()`。
- `frontend/src/components/charts/` 内的业务组件负责数据整理、单位/覆盖字段、tooltip 与选择事件。
- `CalendarHeatmap.vue` 使用原生 Vue/CSS 网格：日历的日期单元、横向滚动和部分覆盖描边保留了原交互；G2 不适合替代该离散网格。本组件不是第二套图表库。

## 数据与验证

页面不补造日级序列、逐条事件、分位数或研究样本。真实模式错误不回退 Mock；未采集、缺失、部分覆盖和真实零分别显示。扩展图表前先核对后端字段、源 API、窗口、单位和样本门槛。

前端构建：

```bash
npm --prefix frontend run typecheck
npm --prefix frontend run build
```
