# GitHubDA V4：中文文案与排版精修

基于 V3 原型直接改进，保留所有 Mock 业务交互，取消宣传式英文眉题、口号式双行大标题，统一自然中文短句与真实工具页面排版。

## 打开方式

- 双击 `index.html`，浏览器打开。
- `app.js` 保存 Mock 状态和业务操作；`styles.css` 为原始布局；`refinement.css` 为 V3 + V4 的覆盖样式。
- 单文件版本 `GitHubDA_中文排版精修原型_V4.html` 可以独立离线打开。

## 主要交互

总览：仓库输入并创建模拟分析；仓库：搜索、筛选、添加、选择、对比、导出；详情：趋势与模块切换、刷新、深度任务；研究：数据集、分组和导出；任务：状态、详情与重试；设置：主题、密度与 Mock 重置。

本页面使用本地演示数据，不连接真实 GitHub 服务；模拟统计不可作为实际项目判断依据。

## 设计调整

- 标题从“用数据，读懂开源项目。”调整为“分析 GitHub 仓库”。
- 删除 `REPOSITORY INTELLIGENCE` 和人为 `<br>` 强制换行。
- 中文副标题缩减为一句，移动端不再出现单字孤行。
- 调整中文系统字体、字号、字重、行高和页面留白。
- 保留 GitHub、Stars、Forks、仓库名等有信息价值的英文。

详细规范另见单独交付的 `GitHubDA_V4_文案与排版规范.md`。
