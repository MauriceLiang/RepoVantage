# RepoVantage 系统截图档案

本目录归档 RepoVantage 用户主站与机器学习控制台的 Safari 截图，便于课程报告、演示材料和交付文档引用。当前共 **49 张**，均以独立图片文件保存；每张分辨率为 **3424 × 2002**。

截图覆盖页面首屏和需要滚动才能看到的内容区。长页面会拆成多张视口截图；弹窗、抽屉等状态会单独保存。列表中的文件名可直接打开原图。

## 截图说明

- 用户主站使用本地 **8501** 服务，机器学习控制台使用本地 **8502** 服务。
- 截图保留页面实际展示的样本数据和图表状态；数据是项目当前本地环境中的页面内容，不代表线上实时状态。
- 长页面按首屏和主要内容区分段截图，便于读者直接定位每个可视化模块。
- 删除仓库、清理任务等确认弹窗只用于展示交互状态，截图过程中没有确认执行这些操作。
