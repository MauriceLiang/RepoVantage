# GitHub 项目比较仓库清单

本清单随项目源码分发，共 **60 个公开仓库、12 个用途分组**。新安装只创建空的“我的仓库”；用户在仓库页点击“导入比较仓库”后，系统才会按下列分组加入仓库，并依清单顺序排队采集。

导入采集范围为最近 90 天的仓库活动，以及最近 12 个完整 UTC 周的维护活动。采集任务由后台 Worker 顺序执行；GitHub 限流或单仓库采集失败时，其他仓库任务仍会继续。

> 分组表示这些项目的主要用途相近，便于横向比较；它不代表项目质量排名。
