# 测试仓库历史事件快照

由本地 `repo-evaluation-2026-v1` 采集库按固定测试组生成，包含截至 2026-11-02 的 180 天 Commit、Issue、PR 与已观察 Release 记录。账号使用仓库内稳定的匿名标识，不包含提交说明、Issue / PR 标题、正文、请求地址或凭据。数据为历史快照，不代表实时状态。

Issue 原始采集只覆盖指定起点之后创建的对象，较早创建后关闭的 Issue 可能遗漏；关闭未合并 PR 的逐条列表也可能不完整。各模块仍按原始采集状态标记覆盖程度。生成命令见 `scripts/build_course_test_events.py`。
