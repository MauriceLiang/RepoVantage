### 数据标识核对事项

目录 `data/datasets/course-research-events-300-v1/` 的 README 和记录内容说明它是 300 仓库事件快照，但其中 `dataset.json` 的 `dataset_id` 当前写为 `course-test-events-v1`，与目录名及 300 仓库规模不一致。使用程序按元数据识别数据集时应先修正并核验该标识；本次仅记录问题，未改数据文件。

## 二、数据清单与抽样文件

`data/manifests/` 保存候选、审核、质量与试点记录：

- `research-candidates.json` 和 `research-candidates-reviewed.json`：各含 4,194 条候选记录；Agent 标注或审核记录不等于最终人工资格确认。
- `research-2026-v1.json`：目标抽样清单状态为 `proposed_pending_owner_confirmation`，候选数 4,194，配额计划为 5 种语言 × 3 个 Stars 区间 × 每格 2 个；本机应用数据库中该正式研究集当前为 0 个成员。
- `featured-v1-candidates.json`、`featured-v1-verification.json`、`featured-v1-quality-report.json`：精选包候选、15 个成员的核验及覆盖质量记录。
- `history-pilot-2026-10-22.json`：历史回填试点检查点验证记录；状态说明完整历史尚未完成。

## 四、本机数据与演示数据

本节的前端演示数据条目于 2026-11-16 按 v4.5 迁移状态复核；其他数据包规模仍以本清单盘点日期为准。

| 路径 | 当前工作区情况 | 是否纳入版本控制 |
|---|---|---|
| `data/app.db` | 本机 SQLite 运行数据库，约 47 MiB，可能随本机使用继续变化 | Git 忽略；不提交 |
| `dataprepare/MachineLearn/run/` | 本机采集与实验目录，约 882 MiB | Git 忽略；不提交 |
| `frontend/src/mocks/catalog.ts` 与 `frontend/src/services/mockRepositoryDataSource.ts` | 显式演示模式使用的仓库、指标和任务种子数据 | 仅在 `VITE_DATA_MODE=mock` 时启用，不是后端数据库或真实 GitHub 数据；`frontend/optimized/` 原型目录已随 v4.5 清理 |

正式前端默认使用 HTTP 数据源；只有显式启用 `VITE_DATA_MODE=mock` 才显示演示数据。HTTP 请求失败时显示错误状态，不静默回退到演示数据。真实 API 接入仍需结合运行后端逐模块核验。

## 五、提交与保管边界

- 本清单列出的已版本化数据包可通过 Git 历史追溯；修改、重打包或替换样本时应更新版本标识、质量报告和哈希。
- 本机数据库和采集运行目录不纳入 Git；提交前检查暂存区，避免添加数据库、token、原始运行日志、个人路径或凭据。
- 快照数据只覆盖其声明的时间窗。缺失、部分覆盖、失败和真实零值应保持区分。
- 当前事件快照不含提交说明和 Issue / PR 标题、正文，因此不能单靠这些数据判断功能适配、产品质量或用户选择难度。
